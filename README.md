# Power Meter Packer (GitHub version)

Open the page, then:
1. Paste your Anthropic API key (console.anthropic.com > API keys). Usage is billed to that key.
2. Add the Granite Excel file and the photos ZIP.
3. Press "Read photos", review, then download the PowerPoint and Excel.

The key stays in the browser tab and is sent only to api.anthropic.com. Never write a key into the file itself.
